# 划词翻译 · 英中（浏览器扩展）

一个轻量的 Edge / Chrome 浏览器扩展，把网页上的英文实时翻译成中文。

- **划词翻译**：选中网页中的英文，即时翻译。单词给出音标、词性与多个义项；短语 / 句子直接译为中文。
- **截图翻译（v1.1 新增）**：针对**无法用光标选中的英文**（图片、Canvas、PDF 等渲染出来的文字），通过快捷键 / 右键 / 工具栏按钮框选截图，扩展会**离线 OCR 识别**后即时翻译，中文浮动显示在选区旁，全程无需复制粘贴。

默认使用免费翻译引擎，开箱即用；也可在设置中接入兼容 OpenAI 的大模型（DeepSeek / OpenAI / Moonshot / 通义千问 / GLM 等）以获得更高质量的译文。

## ✨ 功能特性

| 功能 | 说明 |
| --- | --- |
| 划词即译（英→中） | 选中英文自动弹出翻译浮层，单词含音标 / 词性 / 多义项 |
| 截图翻译 | 框选屏幕任意区域，离线 OCR 识别英文并即时翻译 |
| 完全离线 OCR | 使用 tesseract.js 本地引擎与英文语言包，识别过程不上传任何数据 |
| 免费引擎内置 | 默认免配置即可用（dictionaryapi.dev + Google 翻译接口） |
| 大模型可选 | 支持 OpenAI 兼容接口，一键切换高质量翻译 |
| 自主开关 | 划词、截图均可独立在设置页开关 |
| 多入口触发 | 快捷键 `Ctrl+Shift+S`、右键菜单、工具栏图标，三种方式任选 |

## 🚀 安装（开发者模式加载解压目录）

本扩展以「解压的扩展程序」形式加载，无需上架应用商店：

1. 打开 Edge，地址栏访问 `edge://extensions`
2. 打开左下角 **「开发人员模式」** 开关
3. 点击 **「加载解压的扩展程序」**，选择本仓库目录（含 `manifest.json` 的文件夹）
4. 加载后，在扩展列表中找到「划词翻译 · 英中」，点击「详细信息」可固定到工具栏

> 注：以开发者模式加载的扩展在每次修改代码后，需在 `edge://extensions` 页面点击该扩展的 **「重新加载」** 按钮才能生效。

## 📖 使用方法

### 划词翻译
1. 用鼠标选中网页上的任意英文（单词、短语或整句）
2. 松开鼠标后，翻译浮层会自动出现在选区旁
3. 单词模式显示音标、词性、多个中文义项；句子模式直接给出整句译文

### 截图翻译
1. 触发截图（三选一）：
   - 按下快捷键 **`Ctrl+Shift+S`**
   - 在页面上 **右键 → 截图翻译**
   - 点击工具栏扩展图标
2. 屏幕进入半透明截图模式，拖动鼠标 **框选** 想要翻译的区域
3. 松开鼠标后，扩展对选区做 **离线 OCR → 翻译**，中文结果浮动显示在选区旁
4. 按 `Esc` 可随时取消截图

### 设置
在 `edge://extensions` 中找到本扩展 → 点击 **「扩展选项」**（或工具栏右键扩展 → 选项），可配置：
- **启用划词翻译**：开关划词功能
- **启用截图翻译**：开关截图功能（默认开启）
- **翻译引擎**：`免费引擎`（默认，免配置） / `大模型`（需填写 API 地址、Key、模型名）

## 🔒 隐私说明

- **OCR 完全本地**：截图识别使用 `ocr/` 目录下的 tesseract.js 与英文语言包，图片**不会离开你的电脑**。
- **翻译请求**：免费引擎会向公网翻译接口发起请求；若使用大模型模式，译文请求仅发往你在设置中填写的 API 地址。
- **密钥本地保存**：大模型 API Key 仅存储在浏览器本地 `storage`，不会上传到任何第三方。
- 本扩展不收集、不上传任何个人浏览数据。

## 🗂 目录结构

```
browser-translate-ext/
├── manifest.json          # 扩展配置（MV3）：权限（含 offscreen）、快捷键、脚本注入
├── background.js          # 后台 Service Worker：截图捕获、右键菜单、快捷键、翻译引擎调度、OCR 路由
├── content.js             # 内容脚本：划词浮层 + 截图框选 UI，裁剪后委托后台做 OCR/翻译
├── offscreen.html         # 隐藏文档（MV3 Offscreen Document）：承载本地 OCR 引擎
├── offscreen.js          # 在 offscreen 文档中加载 tesseract.js 并执行离线 OCR
├── options.html           # 设置页
├── options.js             # 设置页逻辑（划词/截图开关、引擎切换、密钥存储）
└── ocr/                   # 离线 OCR 资源（tesseract.js v5）
    ├── tesseract.min.js        # OCR 主库
    ├── worker.min.js           # OCR Web Worker
    ├── tesseract-core.wasm.js  # WASM 胶水代码
    ├── tesseract-core.wasm     # WASM 核心
    └── eng.traineddata.gz      # 英文训练数据（离线识别用）
```

## 🧩 技术栈

- **Manifest V3**：Edge / Chrome 新一代扩展架构（Service Worker + content script）
- **tesseract.js v5**：浏览器端离线 OCR，识别英文文本
- **免费翻译接口**：dictionaryapi.dev（单词释义）+ Google 翻译（句子）
- **OpenAI 兼容接口**（可选）：DeepSeek / OpenAI / Moonshot / 通义千问 / GLM 等

## 📝 已知限制

- 截图翻译依赖 `chrome.tabs.captureVisibleTab`，因此只能截取**当前可见页面区域**，无法截取超出视口的隐藏部分（如需滚动长图，需手动分多次框选）。
- 离线 OCR 针对印刷体英文效果最佳；手写体、艺术字、LOW 分辨率截图识别率会下降，此时可手动核对选区文本。
- 免费引擎存在公网接口限流可能，高频大模型调用需自备可用 API 额度。
